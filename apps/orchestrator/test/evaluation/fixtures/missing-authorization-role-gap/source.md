# 1. Scope & Ticket Triage

This procedure governs how customer support personnel handle locked accounts and multi-factor authentication (MFA) device replacement requests.

# 2. MFA Bypass Workflows

Section 2.4: Tier 1 Support Agents may override customer MFA credentials and generate a temporary bypass code upon verbal caller verification.

# 3. Security Auditing

Section 3.1: All credential modifications are logged to the security event audit stream.

# 4. Privileged Modifications

Section 5.1: Privileged account modifications require secondary approval from an Information Security Officer before execution.
