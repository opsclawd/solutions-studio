# 1. Credential Custody and Handling

This policy applies to all administrative, root, and cryptographic key assets across development and production environments.

Section 3.2: Production root credentials must be stored exclusively in the centralized HSM-backed Secrets Manager. Sharing production credentials over chat, email, or unencrypted media is strictly prohibited.
